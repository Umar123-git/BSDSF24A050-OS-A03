# BSDSF24A050-OS-A03

Custom Unix shell in C (OS Programming Assignment 03).

Build: `make`  
Run: `./bin/myshell`

Features: built-ins (exit, cd, help, jobs, history, set), `!n` history, GNU Readline, redirection (`<`, `>`), pipes, `;` chaining, `&` background jobs, if-then-else-fi, shell variables.
